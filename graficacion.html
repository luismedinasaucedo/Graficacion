Museo Web de la Evolución Gráfica

Autor: Luis Carlo Medina Saucedo

¿Qué es la graficación?

La graficación por computadora (o computación gráfica) es la rama de las ciencias de la computación dedicada a la generación, procesamiento, manipulación y visualización de datos de imágenes mediante algoritmos y hardware especializado. En lugar de limitarse a "dibujar", implica la representación matemática y computacional de la geometría, la iluminación, el color y el movimiento para renderizar escenas en 2D y 3D.

1.- Línea del tiempo de cinco momentos

Computadora DEUCE

La computadora DEUCE (1955) superó la limitación de las salidas físicas (tarjetas perforadas) al introducir un cambio técnico clave: el uso de pantallas de tubos de rayos catódicos (CRT) para visualizar su memoria interna en tiempo real, donde cada punto luminoso representaba un bit.

Sketchpad

Antes de Sketchpad (1963), la computación se basaba en el procesamiento por lotes sin retroalimentación visual directa, lo que limitaba el diseño matemático al papel. Como cambio técnico, Ivan Sutherland desarrolló en el MIT este sistema pionero que permitía al usuario dibujar, modificar y restringir matemáticamente formas geométricas vectoriales en tiempo real sobre un monitor CRT utilizando un lápiz óptico.

Integración de la GPU

Antes de la integración de la GPU, las computadoras dependían exclusivamente del CPU para los cálculos visuales, enfrentando la limitación de severos cuellos de botella al intentar renderizar entornos 3D complejos debido a su arquitectura secuencial. El cambio técnico consistió en la incorporación de un hardware dedicado con una arquitectura de procesamiento paralelo masivo, diseñado específicamente para acelerar las intensas operaciones matriciales, transformaciones geométricas y rasterización de píxeles.

WebGL en Navegadores

Antes de WebGL, la renderización de gráficos interactivos y 3D en la web enfrentaba la limitación de depender exclusivamente de plugins de terceros (como Flash o Java), lo que generaba vulnerabilidades de seguridad, fragmentación y un rendimiento ineficiente. El cambio técnico consistió en la creación de una API estándar en JavaScript, basada en OpenGL ES, que permitió a los navegadores web acceder directamente a la aceleración por hardware de la GPU de forma nativa a través del elemento canvas de HTML5.

Imágenes rasterizadas

Antes de las imágenes rasterizadas, los primeros sistemas dependían exclusivamente de gráficos vectoriales (trazado de líneas), enfrentando la limitación de no poder representar de forma eficiente sombras continuas, texturas detalladas o fotografías reales debido a la carga computacional de usar solo fórmulas matemáticas. El cambio técnico consistió en mapear la imagen como una matriz o cuadrícula bidimensional de puntos discretos, donde cada punto almacena un valor específico de color directamente en la memoria de video.

Modelo de color

RGB

El modelo de color RGB es un sistema cromático aditivo que representa el espectro visible mediante la superposición y mezcla de diferentes intensidades de luz de estos tres colores primarios. A nivel técnico en la graficación, cada canal se codifica normalmente con 8 bits (valores del 0 al 255), lo que permite generar más de 16 millones de combinaciones cromáticas, donde la ausencia total de los tres produce negro y su máxima intensidad genera blanco puro.

CMY

El modelo de color CMY (Cian, Magenta y Amarillo) es un sistema cromático sustractivo utilizado principalmente en la impresión, donde los pigmentos o tintas absorben ciertas longitudes de onda de la luz blanca y reflejan las demás.

HSV

El modelo de color HSV (Tono, Saturación y Valor) es una representación cilíndrica del espacio cromático diseñada en la década de los 70 para alinear la selección de colores digitales con la intuición y percepción visual humana, distanciándose de la mezcla numérica del RGB.

HSL

El modelo de color HSL (Tono, saturación y luminosidad) es una representación geométrica del espectro cromático, similar al HSV, pero estructurada matemáticamente como un cilindro o doble cono donde los colores más puros se ubican exactamente en el nivel medio de luz (50%).

  • Experimento 1: Predicción:que se vea un color oscuro o negro y el max y min sean iguales ,Datos: RGB(128, 128, 128) , Máx / mín / Δ(0 / 0 / 0),Conclusión: Al no haber diferencia entre canales, el tono desaparece (0°) dejando solo un valor de gris.
  • Experimento 2: Predicción: sera un color rojo escuro el primero el segundo uno mas brillante y la propiedad que creo que se mantendrá sera el max ,Datos: RGB(128, 64, 64), max/min/Δ: (128 / 64 / 64),Conclusión: El acercamiento entre canales disminuye la pureza del color, acercándolo al gris.
  • Experimento 3: Predicción: el canal mayor sera el azul y el tono sera un azul-verde oscuro y creo que el brillo sera igual ,Datos: RGB(64, 128, 192), max/min/Δ: (192 / 64 / 128),Conclusión: V y L dan resultados distintos para un mismo color porque representan el brillo de manera distinta el v se calcula exclusivamente con el canal mayor y la L se calcula como el punto de enmedio del max y min.

Pseudocodigo de RGB a HSV

La función recibe los valores enteros RGB (Rojo, Verde y Azul) en un rango de 0 a 255 y debe devolver los valores HSV correspondientes (Matiz, Saturación y Valor).

Primero llevo los canales a una escala de 0 a 1 dividiendo cada uno de los valores de entrada (R, G, B) entre 255.

Después identifico cuál de estos canales normalizados es el mayor (Cmáx), cuál es el menor (Cmín) y calculo el diferencial (delta) restando el menor al mayor. El Valor (V) se iguala directamente al Cmáx.

Si delta es cero, entonces el caso es un tono de gris (o blanco/negro), por lo que el Matiz (H) es 0 y la Saturación (S) es 0; con esto se evita cualquier intento posterior de dividir entre cero.

Si el canal máximo es el rojo, entonces calculo la diferencia entre los canales verde y azul dividida por delta. Si el máximo es el verde, realizo una operación similar pero sumando un desplazamiento de 2. Si el máximo es el azul, sumo un desplazamiento de 4. Finalmente, multiplico el resultado de la rama elegida por 60 para obtener el Matiz preliminar.

Si el tono queda fuera de la escala de 0 a 360 grados (por ejemplo, si resulta ser un número negativo), entonces le sumo 360 para ajustarlo correctamente dentro del círculo cromático.

Devuelvo los resultados en el orden H, S, V, donde H se entrega en grados redondeados, mientras que la Saturación (S = delta / Cmáx) y el Valor (V = Cmáx) se multiplican por 100 para representarlos como porcentajes.

Código en javascript

function convertRGBtoHSV(r, g, b) {
  // 1 y 2. Se reciben los valores RGB y se normalizan a la escala de 0 a 1
  const red = r / 255;
  const green = g / 255;
  const blue = b / 255;
  let h = 0;
  let s = 0;
  let v = 0;

  // 3. Identificar el valor máximo, el mínimo y calcular el diferencial (delta)
  const cmax = Math.max(red, green, blue);
  const cmin = Math.min(red, green, blue);
  const delta = cmax - cmin;

  // El Valor (V) siempre es igual al canal máximo convertido a porcentaje
  v = cmax * 100;

  // 4. Caso límite: si delta es 0, no hay saturación ni matiz
  if (delta === 0) {
    h = 0;
    s = 0;
  } else {
    // Si delta no es 0, calculamos la Saturación (S) en porcentaje
    s = (delta / cmax) * 100;

    // 5. Separación en ramas para calcular el Matiz (H)
    if (cmax === red) {
      h = 60 * ((green - blue) / delta);
    } else if (cmax === green) {
      h = 60 * (((blue - red) / delta) + 2);
    } else if (cmax === blue) {
      h = 60 * (((red - green) / delta) + 4);
    }

    // 6. Ajuste de tono si resulta en un valor negativo
    if (h < 0) {
      h += 360;
    }
  }

  // 7. Redondear los valores
  h = Math.round(h);
  s = Math.round(s * 10) / 10;
  v = Math.round(v * 10) / 10;
  
  return [h, s, v];
}

Glosario de Términos

Píxel

La unidad más pequeña y fundamental de color y luz que compone una imagen digital en una pantalla.

RGB

Modelo de color aditivo basado en luz, formado por los colores primarios: Rojo (Red), Verde (Green) y Azul (Blue).

HSV

Modelo de color diseñado para alinearse con la percepción visual humana, compuesto por Tono (Hue), Saturación (Saturation) y Valor (Value).

Tono

El matiz o color puro en sí mismo (ej. rojo, azul, verde), generalmente representado mediante grados en un círculo cromático.

Saturación

La intensidad, pureza o viveza de un color. Una saturación baja acerca el color al gris.

Valor

El grado de claridad u oscuridad de un color, donde un valor de 0% es negro total y 100% es su máxima luminosidad.

Normalización

Proceso matemático utilizado para ajustar valores a una escala estándar, comúnmente llevando valores (como los canales RGB de 0 a 255) a un rango de 0 a 1.

Caso límite

Situación particular en un algoritmo matemático donde las reglas regulares no aplican, como evitar una división entre cero cuando todos los colores son iguales.

Delta (Δ)

La diferencia matemática entre el valor más alto y el valor más bajo dentro de los canales de color en un momento dado.

Luminosidad

La percepción de cuánta luz parece emitir un color. En modelos como HSL, se calcula típicamente como el punto medio entre el canal máximo y mínimo.
